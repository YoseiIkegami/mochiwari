# MOCHIWARI

旅行・キャンプの共通持ち物を、参加者ごとに分担する小さなWebツールです。未担当の項目、準備済みの件数、担当数の偏りを画面で確認できます。

## 試す

Node.js 22.18以上。

```bash
npm install
npm run dev
```

メンバー名と共用品を入力し、各品目の担当を選びます。分担表をコピーしてグループへ共有できます。

入力内容はブラウザ内のメモリだけで扱います。保存、共同編集、共有URL、認証は提供しません。ページを閉じると消えます。

## 検証

```bash
npm run lint
npm test
npm run build
```

実験仮説：旅行・キャンプ幹事が、LINEなどの会話から外さずに共用品の未担当と偏りを短時間で確認できる。

市場需要・利用継続・課金可能性は未確認です。総合的な持ち物リスト、天気連携、旅程、費用精算、リマインダーは対象外です。進行管理は集約サイト `yosei-site` の `docs/product-loop.json` を正本とします。
